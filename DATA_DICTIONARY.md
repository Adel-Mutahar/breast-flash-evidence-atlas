# Data Dictionary — Breast FLASH Evidence Atlas

The atlas is generated from the final 58-report **Supplementary Material E2**.

- **Study ID**: publication-specific identifier S1–S58.
- **Study / Year / DOI / DOI URL**: bibliographic identifiers from E2.
- **Formal atlas domain(s)**: manuscript-aligned formal domains used for interactive filtering and summary counts. Planning-only lung/OAR mentions are not treated as biological lung evidence.
- **Ledger domain(s)**: source domain wording preserved from E2.
- **Design/model**: experimental setting and model from E2.
- **Modality**: source irradiation modality; the atlas also assigns the manuscript's primary modality grouping.
- **FLASH regimen**: dose/dose-rate/fractionation description from E2.
- **Comparator stratum (ledger)**: source E2 comparator wording.
- **Comparator synthesis stratum**: final 45-report manuscript stratum (≤0.2 Gy/s, >0.2 Gy/s, mixed, not numerically resolved) or outside that denominator.
- **Outcome direction**: domain-specific evidence classification from E2.
- **Key result / interpretation**: publication-facing quantitative or interpretive result from E2.
- **Overlap adjudication**: outcome-level independence/data-reuse handling from E2.
- **Full citation**: citation from the E2 References sheet.

The website is a visualization/navigation layer. If any discrepancy is identified, the submitted/published manuscript and Supplementary Material E2 should be treated as authoritative.
